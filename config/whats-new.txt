# id: 26.11-tools

What's new in this AstroAI image
────────────────────────────────
More command-line tools on every AstroAI image:

  tmux, screen          keep a shell running when the page closes
  rclone                copy to and from cloud storage (current release)
  parallel, pv, aria2   run jobs in parallel, watch progress, fast downloads
  sqlite3, bc, 7z       quick databases, arithmetic, archives
  btop, strace, tig     system monitor, syscall tracing, git browser
  direnv, entr          per-folder environments, rerun on file change
  ping, nc, gpg         network checks, signing

Still here: vos-sync (parallel VOSpace copy) and vosfs (VOSpace from Python).
